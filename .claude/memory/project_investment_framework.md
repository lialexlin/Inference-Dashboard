User's actual thesis (use this lens, not Buffett):

**Demand × Bottleneck × Moat × Exit**

1. **Demand variant perception**: inference demand is under-modeled by the marginal investor because 99% haven't used the tools. User is a daily Claude Code user and views this as edge. Chain: usage → capex → revenue → estimate revisions → price. Be paid for being early.
2. **Bottleneck rotation**: market rotates capital based on which layer is the *binding* constraint at the moment (memory today, plausibly power/cooling or optics next). Want bottleneck-agnostic exposure.
3. **Choke-point moat**: within each layer, own only players who genuinely can't be designed around in 2–3 years. Test: "could a hyperscaler with $80B/yr capex disintermediate them?" Honest list: NVDA (CUDA), TSM (yield), ASML (EUV monopoly), SK Hynix (HBM lead), Google (TPU vertical integration).
4. **Exit triggers**: codified upfront. (a) Token usage growth <30% YoY for 2 consecutive quarters at frontier labs; (b) major hyperscaler cuts capex guide; (c) algorithmic shift collapses FLOPs/token ≥10×; (d) Taiwan geopolitical break.

**Why:** This is a Druckenmiller-style concentrated secular bet, not a 30-year-compounder hunt. Holding period is 2–3 years until clear thesis-break signal.

**How to apply:** When analyzing positions or the dashboard, ask "demand still accelerating? bottleneck still binding? moat still intact? exit trigger fired?" — not "would Buffett own this for 30 years?" Reframe quality metrics (ROIC, FCF) as *durability evidence* under the framework, not as ends in themselves.

**Current positions (as of 2026-05-13):** NVDA, GOOGL, TSM, 000660.KS (SK Hynix), 005930.KS (Samsung). Samsung is the weakest fit — model flags avoid; it's an "everything but worse" overlap with Hynix + TSM exposure.
